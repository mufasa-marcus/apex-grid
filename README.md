# Apex Grid

A responsive, fan-made Formula 1 information website. It has three pages: Home, Driver Standings, and Race Calendar. It has no login, database, or API key: the browser loads the current season's public standings and race schedule from the Jolpica F1 API.

## Publish it

1. Create a new empty GitHub repository called `f1-apex`.
2. Upload these files to that repository.
3. In Vercel, choose **Add New → Project**, select the GitHub repository, and click **Deploy**.

Vercel will give you a public web address that you own and can rename with a custom domain later.

## Notes

- Data updates when the visitor opens or refreshes the website.
- This independent project is not affiliated with Formula 1.
